# DECISIONS (one line each: decision — reason)

- Branch `claude/hummlings-build` with a draft PR — the cloud environment rule is to branch off main and open a draft PR.
- Stage 1 "Moonlit Pond": A minor, 92 BPM, Am-F-C-G; Stage 2 "Candy Fair": C major, 112 BPM, C-G-Am-F; Stage 3 "Sleepy Cloud Town": D major, 84 BPM, D-Bm-G-A — distinct key, tempo and mood per world.
- Loop phase follows the global bar counter (bar mod 4) — a layer joining mid-loop stays in sync with the chord loop.
- Sounds are fully synthesised in code (no downloaded CC0 samples) — keeps every sound original with zero licence risk and no network dependency at build; docs/ORIGINALITY.md records that. Vocal syllables use a formant synth.
- Loops shipped as m4a (AAC) with seamless-loop authoring (tail wrapped into the head) and `loopEnd` set exactly in the engine — AAC encoder delay is absorbed by the loop points; fallback is WAV/FLAC via one config flag.
- Pure TS zod schema in src/core/schema.ts is the fixed content schema (M0) — one validator for build script, tests and app.
- Live master bus uses the audio engine's compressor-as-limiter; export uses the pure `limit()` in core — the audit proves the limiter rarely engages (<= 6 dB), so both sound the same.
- After a celebration the same combo does not re-fire until it has been broken once — avoids nagging confetti while the child keeps playing.
- Songs and progress stored as JSON via expo-file-system (no AsyncStorage) — fewer dependencies, one atomic write.
- Fixed master trim of -6 dB before the limiter — six loops at -20 LUFS each exceeded the 6 dB limiter-reduction budget (measured 7-10 dB); with the trim the audit passes.
- Loop loudness measured as ungated K-weighted LUFS over the whole 4-bar loop; peaky loops (drums) are tanh-saturated (knee 0.55) so peaks stay below -5 dBFS.
- Expo Go is not used (native audio engine): dev client / preview build, as specified.
- Live master limiter is a WaveShaper soft-clip curve (react-native-audio-api has no compressor node); export uses the pure look-ahead limiter — both are inaudible at the audited levels (limiter reduction is 0 dB on typical mixes).
- Song export is WAV 48 kHz 16-bit mono — no free maintained module encodes arbitrary PCM arrays to m4a (the audio library's AAC writer is tied to its recorder).
- Plain state-based navigation in App.tsx instead of Expo Router — 7 screens, no deep links, fewer moving parts.
- Touch handling is a pure `GestureTracker` in core fed by raw RN touch events (no gesture-handler API) — fully unit-tested, supports multi-touch.
- Look sheet audio is mp3 (the artifact host does not serve m4a); the app itself ships m4a.
- Art redo after look-sheet feedback ("creatures are ugly"): generic blobs replaced by 8 recognisable species (cat, bunny, bear, mouse, frog, bird, dino, axolotl) with kawaii faces (big low eyes, blush, tiny mouth, belly), still drawn in code and still one body family per layer. Schema field `ears` became `species`.
- Look and sound approved by Yonatan ("סבבה") — art direction is now final.
- "More melodies": kept 16 creatures per world (tray, schema and the 8,008-combo audit depend on it) but every melody creature of every world is now a different composed tune (rhythm cell x world contour, test-enforced). Adding more melodies later = add cells/contours in src/core/patterns.ts.
- Owner asked for a richer game and a beginner's guide (supersedes the v1 counts): 24 creatures per world (6 per layer, 72 total), 4 combos per world (12 combos, 12 celebrations), 84 loops. Layers keep their colour-coded tray groups (6 each). TUNING.perLayer / combosPerStage drive everything.
- Mix audit with 134,596 combinations per world is infeasible; it now covers every 6-combination of the 9 loudest-peak loops plus 8,008 seeded random combinations per world (fast check: 120 random).
- How-to-play guide: 7 short animated lessons (same scene code as the game) with one sentence each, en/he; reached by a "?" button on stage select (pulsing badge until first opened) and on the stage top bar. This adds text to an otherwise text-free first run, by the owner's request.
- Opening the guide from a stage leaves the stage (it restarts on return): acceptable for v1, noted for polish.
- Playable web demo (artifact): Canvas 2D + Web Audio in web/ (esbuild bundle of the real src/core logic, gesture tracker and layout), sprites pre-rendered by the real Skia draw code, mp3 loops. It is a preview for the owner, not a shipped build (celebrations and ear sway are simplified; no recording). The native app remains Skia + react-native-audio-api.
- UX pass after owner feedback: drop-target highlight under a carried creature, "+" marks on empty spots while the stage is young, mute (speaker slash) and solo (star) badges on stage creatures, bigger tray creatures with scroll-edge fades, staged coaching tips and a rotate-to-landscape notice (web demo), icon buttons.
- Depth pass (owner: "not enough"): 8 stickers per world earned by play (full band, drum circle, choir, packed stage, spotlight tour, mix master, swap shop, secret keeper) with progress bars in the combo book; a band meter (4 layer lights) on stage; UI sounds (pickup, drop "pop" re-pitched to the stage's pentatonic scale per spot, mute/unmute, remove, sticker, combo) and an automatic drum fill at the end of a 4-bar loop when 3+ layers play; richer animation (ear/tail sway poses, floating notes, drop sparkles, per-world decor, fireworks and a banner on combos, floor rim breathing with the beat). Stickers are cosmetic and never gate content.
- Worlds made truly different (owner request): per-world creature material (gummy / striped sprinkle candy / fluffy cloud puffs), own species mix (+sheep, fox), own accessories and smaller hue shifts (layer colours stay recognisable); own drum kit (lo-fi round / bouncy snappy / soft brushed); a quiet ambience bed per world (pond: pad, crickets, water plinks; fair: calliope arpeggio; clouds: wind and chimes) at -30 LUFS; own scenery and floor (moonlit water with reeds and reflection / ferris wheel, tents, striped stage / crescent moon, cloud houses, puffy floor); and a tap-the-scenery toy that plays a scale note with a world-specific effect (ripples / popping confetti / star sparkle). Scenery and the tap toy are in the web demo; porting scenery to the Skia scene is still to do.
- Long press now opens a per-singer volume popup (owner request) instead of soloing: hold, then drag up/down (or tap/drag the slider) to set the level; a star button in the popup gives solo. Volume is part of stage state and the recorded timeline (coalesced per bar), applied live (smoothed) and in the offline export; a thin level bar shows next to any singer turned down. Popup and gestures are pure core (tested) and drawn by the shared Skia scene.
- Volume is shown on the creature itself (owner request): colour fills the body up to the volume level and drains to grey above it, with a thin line at the level; the separate side bar was removed.
- Drained part of a turned-down singer is more transparent (30%); volume near zero (<3%) counts as silent for the mix, combos and stickers (owner left the choice open).
- Visibility pass (owner request): bigger solid toolbar buttons (52 px, 2 px light border, pressed/hover states) with visible text labels from 980 px up and icon+label captions under the native buttons; band meter chips with drum/bass/note/mouth icons and names; layer captions (web) and layer icons (shared Skia scene) on the tray groups; a single "closest combo" hint instead of three dot rows; yellow high-contrast coaching bubble; percent readout under the volume slider; pulsing help button until opened; brighter secondary text.
- One emblem per world (owner request): moon over rippling water with lily pad (pond), ferris wheel (fair), cloud with crescent moon and star (clouds); defined once as SVG shapes in src/core/worldIcons.ts and used on stage cards, the stage top bar, the unlock screen (app) and the world buttons and loading screen (web).
- Full mix audit (8,092 combinations per world: all 6-combinations of the 9 loudest loops + 8,008 random) found 6.33 dB limiter reduction in the candy world (over the 6 dB budget): master trim lowered from -6 to -7 dB; re-audit: pond 5.57 (at -6, lower now), fair 5.33, clouds 3.37 dB, peaks -1.00 dBFS. Offline export of a 3-minute, 6-layer song takes about 1.2 s in Node (budget 10 s on Pixel 6a).
- Melody timbres softened after owner feedback ("a bit harsh"): harmonic FM bell, fewer partials, double low-pass (2.6-3.8 kHz), soft attack, register capped at C6 (was G6), bonus sparkle moved down; energy above 2.5 kHz dropped by 4-10 dB.
- Read-free UI (owner request): web demo has no instructional text — pictogram tips (hand + arrow + glow, tap/hold/swipe pairs), icon-only toolbar and world buttons, band chips and tray groups marked by layer glyphs, combo hint as dots plus found-stars, sticker book as pictograms with progress dots, toasts as icons, help lessons as looping videos, rotate hint and splash as icons. The app keeps its captions but gains icons on every settings row; its help lessons are animated.
- Swipe to close the volume menu (owner request): a sideways swipe (>= 40 px, clearly more sideways than vertical) across the popup closes it; vertical drag still sets the level; tapping outside also closes. Pure gesture logic with tests.
- Correction after owner feedback: "close the voices menu by swiping" meant the singer tray, not the volume popup. A downward swipe on the tray now slides it away (stage view grows into the space) and a handle tab at the bottom edge (tap or swipe up) brings it back; upward drags still pick singers up and sideways swipes still scroll. The volume popup keeps its sideways-swipe-to-close.
- Text restored where it helps (owner: "not remove text entirely"): toolbar labels, world names, layer names, sticker names and descriptions, help sentences, short toasts; icons stay next to them. The yellow coaching bubble is removed (the animated first-run hand remains).
- Design refinement pass: toolbar grouped (worlds | actions | band + combo hint) on one 8 px rhythm with a soft scrim, uniform 52 px pills with shadow and a selected ring, labels shown only when there is room (>=1560 px), world names full >=1000 px and short below, HUD wraps as a unit to a second right-aligned row on narrow screens, smaller first-run hand.
- Overlay fix (owner screenshot: toolbar and HUD covered the singers): the stage layout now reserves the toolbar height (topInset) and shrinks singers so the tallest fits below it; on short screens (<540 px high) the toolbar is one compact 44 px row with icon-only worlds and a small HUD; tray singers sit on the tray floor with a caption row above them and captions stay inside their own group (no overlapping text).
- Two more worlds (owner request): "Neon City" (E minor, 100 BPM, dark glowing "neon" creatures, electro kit, synth-arpeggio and rain ambience, skyline and perspective grid) and "Frosty Peaks" (F major, 88 BPM, translucent "frost" creatures with facets and sparkles, glass kit, wind and ice chimes, aurora, mountains and snowfall). 5 worlds, 120 creatures, 20 combos and celebrations, 145 audio assets. Melody contour families went from 3 to 5 so every melody stays unique. Master trim lowered to -8 dB (frost drums pushed the sampled audit to 6.04 dB). Worlds 2-5 are in the single unlock.
- New feature: "Surprise" dice button puts a random six-singer band (every layer present) on the stage, with a sound (pure `randomBand`, tested; web and app).

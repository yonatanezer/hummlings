# ORIGINALITY — origin of every asset
- Creatures, stages, UI, logo, icons: drawn in code (Skia) in this repo. Original designs.
- Sounds and music: synthesised by `npm run sounds` (scripts/) from oscillators, noise and formant filters. No samples, no third-party audio.
- Fonts: system fonts only.
- The only idea taken from anything else is the generic mechanic "drag characters onto a stage to add looping layers".
